# Gabinete Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/gabinete/` — a cabinet roster where each minister has a tenure history and a sourced judicial dossier.

**Architecture:** Three JSON entities (`portfolios` / `people` / `tenures`) read at build time by two pure-function libraries (`cabinet.mjs`, `judicial.mjs`) and rendered by static Astro pages. Roster provenance is the El Peruano gazette via a deterministic parser; judicial records are hand-curated with a per-claim source enforced by the validator.

**Tech Stack:** Astro (static), Tailwind v4, Node `node:test`, Python 3 stdlib, `unittest`.

## Global Constraints

- User-facing copy is **Spanish (Peru)**; code, keys, and comments are **English**.
- **No AI in any pipeline** — parsing is deterministic regex.
- **No scraper writes cabinet data.** Discovery files GitHub issues; humans PR.
- Astro libs read JSON via **static ESM imports** — `fs` reads break under the bundler.
- Components with their own CSS/JS get a **folder module**; Tailwind-only stay flat.
- Colors come from the existing `@theme` tokens: `rojo`, `ambar`, `verde`, `plomo`, `tinta`, `tintasuave`, `tintafina`, `papel`, `carton`.
- Run `npm run validate` after any edit under `src/data/`.

## Discovered context (2026-07-27)

`busquedas.elperuano.pe` was rebuilt as a React Router v7 app. **`/api/graphql` now returns 404** — `elperuano_scraper.py` is broken in production and the daily discovery job has been failing. Task 1 repairs it; every later gazette task depends on that.

Verified replacement:

```
GET https://busquedas.elperuano.pe/_root.data
      ?fechaIni=YYYYMMDD&fechaFin=YYYYMMDD&tipoPublicacion=NL&ci=ONLY
      &paginatedBy=<=500&start=<n>
```

- Response is **turbo-stream**: line 1 is a flat JSON array; objects reference entries by index, and keys of the form `"_12"` mean "the key is `arr[12]`". Negative indices are `null`.
- Payload path to results: `root → "routes/_index" → "data" → "results"` with `totalHits`, `start`, `hasNext`, `paginatedBy`, `hits`.
- `paginatedBy` is honored up to **500**. `sector` and free-text params are **silently ignored** — do not rely on them.
- **Field renames vs the old GraphQL:** the norma number moved `nombreDispositivo` → `numeroDispositivo`; `sector` is now a numeric id string and the human-readable name lives in `distributor`; `urlPDF` is now a site-relative path.
- `/api/visor_html/<op>` is **unchanged** and still returns full norma HTML.

Real captured payload: `tools/tests/fixtures/singlefetch_nl_20260727.data`.

**Data availability:** the new government is sworn in 2026-07-28, so the cabinet's appointment normas do not exist yet. Task 5 builds and unit-tests the parser; running it against the real roster happens on/after 2026-07-28. Tasks 2–4 and 6–8 do not depend on it.
